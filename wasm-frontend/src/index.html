DeepVariant in the browser — dv-wasm + onnxruntime-web

Run the DeepVariant WGS model end-to-end on a tf.Example shard, entirely client-side. Decoding via the Rust → WASM port; inference via onnxruntime-web. The model is fetched once and cached; results download as a .tar.gz.

Input format: a tf.Example shard (gzipped TFRecord, e.g. examples.tfrecord.gz from dv make-examples). Direct BAM/CRAM input in the browser isn't wired yet — make-examples needs to be ported to WASM first (why: BAM/CRAM I/O lives in dv-io which isn't in the wasm build).
