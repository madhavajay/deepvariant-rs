DeepVariant-rs — runs entirely in your browser · no upload · WebGPU

Drag a BAM and its matching reference FASTA. Everything — BAM parsing, make-examples, the neural net (onnxruntime-web / WebGPU), postprocess — runs locally in WebAssembly. Nothing is sent anywhere.

Why a reference FASTA? A BAM contains aligned reads but not the reference genome. DeepVariant calls variants by comparing reads to the reference (pileup channels, candidate REF alleles, realigner) — so the FASTA is required (native dv pipeline always takes --ref-fasta too). It only needs to cover your region: a contig/region slice .fa is enough — you do not need the whole 3 GB genome. A .bai/.crai index only speeds up region access; it is not a substitute for the reference.
