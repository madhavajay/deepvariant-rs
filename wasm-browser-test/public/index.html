DeepVariant in the browser — dv-wasm + onnxruntime-web

Pick a tf.Example shard (gzipped TFRecord, e.g. testdata/quickstart_chr20_norealign/examples.tfrecord.gz). The page decodes each example via the dv-wasm Rust port, runs the WGS ONNX model with onnxruntime-web, and prints the 3-class probabilities. If expected.json is present, results are diffed against the native dv call-variants reference.
